  - [Upload new media](https://developer.orangelogic.com/reference/upload-new-media.md): Upload a single file from your computer to Orange Logic
  - [Upload new version](https://developer.orangelogic.com/reference/upload-version.md): Upload a single file from your computer to Orange Logic as a new version of an existing asset

    - [Step 2: Register upload assets](https://developer.orangelogic.com/reference/register-upload-assets.md): Register each asset you’ll upload as part of the transaction created in the previous step
    - [Step 3: Chunk assets](https://developer.orangelogic.com/reference/chunk-assets.md): Split assets into chunks that will be uploaded into Orange Logic simultaneously
    - [Step 4: Upload each asset chunk](https://developer.orangelogic.com/reference/upload-chunks-to-orange-logic.md): Use one API call per asset chunk to upload all chunks to Orange Logic
    - [Step 5: Complete the upload session](https://developer.orangelogic.com/reference/complete-the-asset-upload.md): Notify Orange Logic that all of an asset’s chunks have been successfully uploaded
    - [Legacy calls](https://developer.orangelogic.com/reference/multi-part-upload-legacy-calls.md): Legacy calls used to complete the multi-part asset upload
